# Plan — Phase 4.4: Concealment + Ambush (marquee mechanic)

Architect-authored implementation plan. The squad starts each mission **concealed**;
while concealed it repositions/scouts freely and pods cannot escalate via sight. The
player chooses when to break stealth (first aggressive action, or stepping too close);
springing the ambush grants a bonus and resumes the normal 4.3 alert-tier rules.

> Verify all illustrative APIs against the real code (field/method names in `Combat.cs`,
> `Unit.cs` may differ from the sketch below — adapt, don't assume).

## State
- `Game.SquadConcealed` (bool). Consts: `Game.RevealRange = 3`.
- `Unit.FiredFromConcealment` (bool) — transient per-mission; cleared in `Unit.BeginTurn()`
  alongside `RunGun`/`Blitz`/`Steady`; never persisted.
- `Combat`: consts `AmbushAim = 20`, `AmbushCrit = 25`; add `bool Ambush` to the odds struct.
- **SaveGame: NOT persisted** — concealment is per-mission, re-initialized in `SetupMission`.

## Init / reset
- In `SetupMission`, after `Phase = Phase.PlayerTurn`: `SquadConcealed = true;`
- In the per-player reset loop (where feats/statuses clear): `u.FiredFromConcealment = false;`

## Gate (the core mechanic) — `CheckPodActivation`
Run `TryFreeCaptive()` FIRST (captive proximity isn't aggression), THEN
`if (SquadConcealed) return;` before the pod-escalation loop. While concealed, no pod
goes Suspicious or Alert via sight. `ResolveSuspicion` needs no change (it finds no
Suspicious pods while concealed).

## BreakConcealment(Unit actor = null)
`if (!SquadConcealed) return;` → set false; if `actor != null` set `actor.FiredFromConcealment = true`;
`ShowBanner("AMBUSH!", false)`; `Fx.AddShake(4f)`; a punchy sound (`Audio.Play("turn")` is fine);
then wake every pod currently in sight: for each dormant enemy with `ClosestSightedDist(e) >= 0`,
collect `PodId` into a set and `ActivatePod(pid)` (the existing 4.2 capped single-move scatter
applies — a squad breaking stealth IS the surprise, so the same cap is correct).

## Break triggers — call BreakConcealment BEFORE the action mutates state
- `IssueShoot`: before `Ammo--`, `if (SquadConcealed) BreakConcealment(Selected);` — and AFTER
  `Combat.Resolve(...)`, set `Selected.FiredFromConcealment = false;` so the bonus applies to the
  ONE breaking shot only (a RunGun second shot won't re-use it).
- `IssueGrenade`: before `Grenades--`.
- `DoAbility` SUPPRESS case: before the pin fires.
- `IssueItem` FLASH only (smoke/barricade are not aggression).
- **NOT** `DoHack`/PLANT — objective actions are allowed while concealed (a stealth ghost-run is
  a valid, rewarded scenario; the board is fully visible so the player sees the risk).
- `OnUnitEnteredTile` (player mover): if `SquadConcealed` and any **active** enemy is within
  `RevealRange`, `BreakConcealment(mover)` (no `FiredFromConcealment` — it's a proximity break).
- `AutoStallCheck`: if `SquadConcealed` call `BreakConcealment()` before the force-activate.

## Ambush bonus — `Combat.ComputeOdds`
`if (a.FiredFromConcealment) { hit += AmbushAim; crit += AmbushCrit; }`; set `odds.Ambush = a.FiredFromConcealment`.

## Autopilot — `AutoStep` (test-only; must avoid TIMEOUT)
After selecting the actor `u`, if `SquadConcealed`: break when any player has a valid target
(reuse the existing has-a-target helper), OR (fallback) when any player is within ~6 tiles of a
dormant enemy. Else fall through to normal movement. Belt-and-suspenders with `AutoStallCheck`.

## HUD / Renderer (ASCII-only; keep existing shots stable)
- `Hud.DrawTopBar`: a pulsing "CONCEALED" pill (`Pal.Friend`) when `SquadConcealed` (no
  "EXPOSED" text when broken — absence + newly-revealed enemy glyphs communicate it).
- Tooltip: a `+ AMBUSH` line when `HoverOdds.Ambush` (mirrors `+ HIGH GROUND`/`+ STEADY`).
- `Renderer.DrawUnit`: friendly non-VIP units get a faint pulsing `Pal.Friend` ghost ring while
  `SquadConcealed` (only runs when concealed, so it can't perturb post-break shots).

## Edge cases
- **Defend**: waves spawn pre-Active; concealment still starts true and breaks via `RevealRange`
  when a wave closes in, or when the player shoots. Correct.
- **Escort/Rescue**: moving the VIP/freeing the captive does NOT break concealment (not aggression).
- **Turrets/immobile pods**: can't wake by sight while concealed; on break they get 0 scatter (Mobility 0).
- **Never-break**: Evac/Hack/Sabotage/Rescue can be won without ever shooting (ghost run) — valid.

- New `SIGHTLINE_CONCEAL=1` → `DebugConcealment()` shows a banner for the screenshot.
- Build Release 0/0; `SIGHTLINE_COMBATTEST=1` PASS; `SIGHTLINE_AUTOPLAY=1` ×5 (WIN/LOSE, never

## Risk / rollback
Single self-contained commit. Rollback = set `SquadConcealed = false` in `SetupMission` (all new
paths are gated on it), restoring exact 4.3 behavior.

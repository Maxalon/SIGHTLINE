### TWO ASSERTIONS THIS EXERCISE FOUND TO BE THEATRE, AND WHAT REPLACED THEM
1. `killSigNoDeathWord` originally read `k.Texts < 1`. B13 - deleting KillUnit's KIA/DOWN pop
   outright - PASSED, because the killing blow's own damage number was still on screen. A channel
   COUNT cannot see a missing word. It now checks the word BY NAME (FeelAnswer.Words).
2. `Seen` originally included `Queued` (anims enqueued). B17 - guarding ShotAnim.Apply out entirely -
   did not raise outcomeUnseen, because the now-inert anim was still on the queue. An enqueued anim
   is a PROMISE that something will be drawn, not evidence that anything was. `Queued` is now a
   reported column only; `Moved` (a watched figure's drawn position actually changed) took its place
   in the sum.
Both are recorded here rather than quietly fixed: they are the exact failure mode this project has
had to tear out twice before, and the only reason they were caught is that every assertion was
required to be shown red.
